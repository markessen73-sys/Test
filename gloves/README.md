# Boxing glove images

Drop your realistic glove photos here to replace the built-in SVGs.

| File | Used for |
|------|----------|
| `boxing-glove-left.png` (or `.webp`) | Left glove — overrides SVG if present |
| `boxing-glove-right.png` (or `.webp`) | Right glove — overrides SVG if present |
| `right-zones/zone-r*-c*.png` | Default / gold padded glove zone pack |
| `bare-knuckle-zones/zone-r*-c*.png` | Bare knuckle hand-wrap zone pack |
| `vintage-zones/zone-r*-c*.png` | 1920s brown lace-up glove zone pack |

**Tips for best results**
- Transparent background (PNG/WebP)
- Glove pointing toward camera, roughly 400×480px or similar aspect
- Same lighting angle on left and right if using two separate images

If only one image is provided, name it `boxing-glove.png` and it will be used for both hands (right flipped).

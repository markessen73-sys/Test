# Starvault Skimmer

Starvault Skimmer is a clean-room retro space arcade game inspired by the feel of early home-computer cave navigation games. It uses Phaser 3, fixed-screen room progression, precise 4-way ship movement, instant-death hazards, and on-screen touch controls for mobile.

## Run locally

- `npm install`
- `npm run dev`
- `npm run build`

## Controls

- `Left Arrow` / `Right Arrow` - move horizontally
- `Up Arrow` / `Down Arrow` - move vertically
- `Esc` - pause
- Mobile - use the on-screen directional buttons

## Game loop

1. Survive the Hangar Shaft.
2. Cross the Lift Corridor and use the warp pad.
3. Reach the Core Vault and collect the relic.
4. Restart from the first screen at a slightly faster pace.
